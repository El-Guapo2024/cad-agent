# pcb_conveyor — mechanical spec

## Brief

One module of a production-grade SMEMA edge-belt PCB conveyor for the open PCB line: aluminium extrusion frame, machined rails, flat belts driven from one motor through a shared hex shaft, rear rail width-adjusted on linear guides by two synchronised lead screws. Layout after SuperHouse's PCBCONVEYOR (TAPR OHL, Jonathan Oxer); interface numbers from SMEMA Interface Standard 1.2.
